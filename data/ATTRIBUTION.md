# Data attribution

The public benchmark used in the LinuxONE notebook was UCI Bank Marketing: Moro, S., Rita, P., & Cortez, P. (2014), UCI Machine Learning Repository, DOI: https://doi.org/10.24432/C5K306. The project's documentation identifies the dataset as CC BY 4.0; retain attribution if redistributing adapted data. The full dataset is not included in this repository.

Download page: https://archive.ics.uci.edu/dataset/222/bank+marketing

The bundled `data/candidate.csv` is a five-row synthetic demonstration fixture, not copied from the UCI data.
